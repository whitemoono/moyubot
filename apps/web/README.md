# MoyuBot 自建移动端 PWA

手机优先的 PWA，可独立 Docker 部署。每个用户使用自己的服务器，客户端没有默认公共同步地址。未配对时展示示例内容；配对并主动开启同步后，使用当前自建工作空间的数据。桌面明确授权服务商和云电脑后，手机可选择模型聊天、通过服务器操作云电脑；真实通知尚未接入。

视觉采用纯白／纯黑与中性灰，角色头像保留原色。`src/monochrome.css` 管理中性玻璃质感，`src/motion.js` 管理弹簧运动：底栏连续滑动、速度驱动的胶囊拉伸、按钮回弹、页面过渡、底栏拖动和弹层下拉。运动优先使用 transform 与 opacity，不在逐帧动画中更改背景模糊。这是网页近似效果，并非系统原生 Liquid Glass；支持减少动态效果与无背景模糊时的降级。

在仓库根目录启动（复用现有桌面端 Vite，不需要额外安装）：

```sh
npm run dev:web
```

打开 http://localhost:5174/。桌面浏览器呈现手机画框和页面导航；手机宽度时直接铺满屏幕。支持对话、伙伴、工作台、个人空间、聊天详情、搜索与配置弹层，以及浅色和深色主题。

```sh
npm run build:web
```

静态产物输出到 `apps/web/dist/`。已包含 manifest、主站品牌图标、Service Worker 应用壳离线缓存和 IndexedDB 离线队列。桌面头像中的「连接手机」填写自建服务器地址、连接密钥，再用手机扫码，桌面确认后配对。两端同步开关独立，默认关闭。

独立部署、连接与备份说明见 [DEPLOY.md](./DEPLOY.md)。同步服务默认禁用，部署者需显式设置自己的域名和连接密钥并启用。公开界面预览不提供公共数据后端。

头像直接引用现有桌面端角色数据，没有复制或更改源素材。来源和授权范围见 `../../docs/ASSETS.md`。其他图标为本原型的内联 SVG，云电脑插画使用 CSS 绘制。
