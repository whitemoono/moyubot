description: 当用户要求测试 MoyuBot 的 MCP 与 Skill 联动、运行能力验收或检查测试 MCP 时使用。通过读取技能参考文件、回声和加法调用验证实际接入。
---

读取本技能的 `references/check-case.md`，获取本次测试的校验短语和两个数字。

在当前可用工具中找到「MoyuBot 测试」服务的 `echo` 和 `add_numbers`；工具在模型接口中的名字可能带有自动生成的前缀，使用已提供的真实工具名。

1. 调用 `echo`，text 使用参考文件中的校验短语。
2. 调用 `add_numbers`，a 和 b 使用参考文件中的数字。
3. 依据真实结果输出简短验收记录：参考文件是否读取、回声是否一致、加法输入和返回值、工具返回的调用时间。

只有两次调用都成功、回声一致且加法结果正确，才确认联动测试通过。工具缺失、失败或用户拒绝调用时，说明未完成的项目及原因，不能使用心算或自行生成的时间替代返回结果。
