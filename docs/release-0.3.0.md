## 更新内容

### MCP 与 Skills 页面：按来源分组折叠

之前两栏里各塞了列表、空状态、云端清单、导入区四块，嵌套一堆折叠框，看着很乱。现在每个栏目内部**按来源分成可折叠的组**：

- **MCP 服务**：工作区配置（N）· 云电脑共享（N）· 各 Bot 自有（N）
- **技能**：工作区配置 / 本地技能库（N）· 云电脑共享（N）· 各 Bot 自有（N）

组的标题就是一行「▸ 云电脑 · 共享  `10`」，**默认全部收起**，一屏就能看完分组概览；点开才展开条目。导入 MCP JSON 变成点「添加」后**就地展开**，不再长期占一块。

### 工具页：默认全部折叠

39 个工具分成 12 组后，默认**全部收起**，只显示每组标题与数量；想看哪组点开哪组。顶部搜索框会自动把匹配到的组展开。
