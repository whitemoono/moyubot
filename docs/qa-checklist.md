# MoyuBot 手工测试清单（v0.1.3 完整版）

> 前提：使用最新构建——开发者版（标题 **MoyuBot Dev**）或安装包 `apps/desktop/release/MoyuBot.Setup.0.1.3.exe`。
> 云电脑相关用例需要云机可唤醒（instabox 或 E2B 驱动）。每条给出「操作 → 预期」，失败记录截图。

## A. Bot 与工具默认值

- [ ] **A1 出厂默认 Bot**：全新数据目录启动 → 默认 Bot 名为「大肥鱼」，handle `dafeiyu`，头像字符「鱼」
- [ ] **A2 工具默认全量**：打开任意 Bot 编辑页 → 23 个工具全部显示为开启（`tools: []` 语义：除 install_* 外全量）
- [ ] **A3 开关语义**：关掉一个工具 → 保存 → 重开编辑器 → 只有它显示关闭，其余仍开启；重新打开它并保存 → 检查 settings.json 中该 Bot `tools` 变回 `[]`
- [ ] **A4 新建 Bot 全量**：新建一个 Bot → 编辑页工具全开；对话里能调用 `set_goal`（下方 C 组验证）
- [ ] **A5 安装类 opt-in**：默认下 `install_mcp`/`install_skill` 显示为关闭（安全设计），手动打开后可用

## B. 每 Bot 工作目录（文件隔离）

- [ ] **B1 云端目录**：对 Bot A 说「在云电脑用 pwd，然后写一个 note.md 内容是 A」→ 输出落在 `<remoteWorkspaceDir>/<BotA名>/`（如 `/data/home/moyubot/大肥鱼/`）
- [ ] **B2 云端隔离**：对 Bot B 说「列出当前目录文件」→ 看不到 A 的 `note.md`
- [ ] **B3 本地目录**：本地工作区 Bot 重复 B1 → 文件落在 `<本地工作区>/<Bot名>/`
- [ ] **B4 改名不换目录**：把 Bot 改名 → 文件仍在原目录（dirName 首次推导后固定）

## C. 目标（set_goal / update_goal）与头部胶囊

- [ ] **C1 立目标**：发送「用 set_goal 给这次会话立个目标：整理一份 moyubot 工具清单摘要。验收条件三条：(1) 列出全部工具名 (2) 按功能分组 (3) 标注哪些需要联网。autonomy 设 until_done」→ 头部出现目标胶囊 `目标 ✓ 0/3 ⟳ 0/8`
- [ ] **C2 浮层**：鼠标移到目标胶囊 → 浮层显示完整目标 + 三条验收条件 + 续航轮数；**不透明可读**；Esc 关闭
- [ ] **C3 受阻与续跑**：发送「用 update_goal 把当前目标标为 blocked，note 写"演示"」→ 胶囊变琥珀色「续航暂停」；浮层点「续跑 5 轮」→ 恢复续航态
- [ ] **C4 带证据完成**：让 Bot 完成三条并 `update_goal complete`（附证据）→ 目标胶囊**消失**；未满足条件时标记完成会被运行时拒绝并要求补证据
- [ ] **C5 人工完成**：立新目标后直接点浮层「标记目标完成」→ 确认后胶囊消失
- [ ] **C6 胶囊可点击（回归）**：用**真实鼠标**点击胶囊（不是合成事件）→ 浮层必须打开；若点不动即为 pointer-events 回归

## D. 任务清单（todo_write）胶囊

- [ ] **D1 出现**：让 Bot `todo_write` 立 3 项清单 → 头像**左侧**出现清单胶囊 `0/3`
- [ ] **D2 进度**：完成 1 项后 → 胶囊 `1/3`（未全部完成才显示）
- [ ] **D3 全部完成消失**：三项全完成 → 胶囊自动消失；消息流里的「任务清单已更新」工具行保留记录
- [ ] **D4 多轮重现**：新一轮 `todo_write` → 胶囊重新出现
- [ ] **D5 浮层**：hover 显示完整清单（勾选态、完成项划线）

## E. 子代理胶囊（spawn / run_script / fork / control / list）

- [ ] **E1 spawn 并行**：发送「用 spawn_agent 并行派 3 个子代理：分别总结 cloud_* 工具、记忆工具、联网工具的用途」→ 目标胶囊**右侧**出现子代理胶囊 `⟳ 1/3 → ⟳ 2/3 → 子代理 3`；浮层实时显示每个子任务状态（… / ✓ / ✗）
- [ ] **E2 run_script**：发送「用 run_script 写脚本：用 agent() 并行总结两类工具，汇总返回」→ 胶囊计数 + 工具卡显示阶段与子代理数
- [ ] **E3 fork 进胶囊（回归）**：发送「用 subagent_fork 带着当前上下文继续：指出最值得深挖的一点」→ 胶囊多出一个分身批次（虚线分隔），浮层可见任务
- [ ] **E4 list/control**：发送「列出这个对话派过的所有子代理」（拿到 id）→ 再发送「用 subagent_control 向该子代理追问：把结论压缩成一句话」→ 子代理被重新唤醒并返回；`stop` 对运行中的有效
- [ ] **E5 会话隔离**：切到另一个 Bot 的会话 → 子代理胶囊不显示前一个会话的批次
- [ ] **E6 工具卡一致性**：胶囊里每个子任务状态与消息流工具卡里的进度一致（运行中转圈 → 完成打勾）

## F. 输入框与附件

- [ ] **F1 长文本**：粘贴 300+ 字 → 输入框长到 80vh 内完整显示（全宽、无滚动条）；粘贴后光标在末尾且视口贴底
- [ ] **F2 聚焦样式**：点击输入框 → 无黑色 focus 外框，容器边框泛柔光
- [ ] **F3 全屏拖入层**：从资源管理器拖图片+文件到窗口**任意位置**（不是输入框）→ 全屏毛玻璃层「拖入图片或文件到此处添加」；在任意位置松手都能接住
- [ ] **F4 混排 chip**：拖 1 图 + 1 xlsx → 附件行显示缩略图 chip + 文件 chip（图标/文件名/大小）；可单独 × 移除
- [ ] **F5 超限提示**：拖 >8MB 图片 / >20MB 文件 → toast 提示跳过（不再静默）
- [ ] **F6 发送与渲染**：图片+文件一起发送 → 用户气泡内缩略图 + 可点击文件 chip（点击打开文件）
- [ ] **F7 落盘与 Bot 感知**：文件存到 `uploads/<bot>/`；问 Bot「我发的文件内容是什么」→ 能读到附件路径并给出内容

## G. 提问卡（ask_user）

- [ ] **G1 卡片位置**：发送「测试 ask_user：用 ask_user 问我一个开放问题」→ 提问卡出现在**输入框上方**（非全屏遮罩，聊天背景可见可滚）
- [ ] **G2 交互**：Ctrl+Enter 发送回答 → 卡片消失、Bot 引用你的回答继续；Esc 或「跳过」→ Bot 说明"用户跳过"并举出假设
- [ ] **G3 跨会话兜底**：在会话 A 聊天时让会话 B 的 Bot 提问 → 全局弹层兜底出现（不阻塞 B 干等）

## H. 计划模式

- [ ] **H1 切换**：输入框上方切「计划模式」→ Bot 只能只读工具，提交 `exit_plan_mode` 计划
- [ ] **H2 批准验收**：计划必须**问人批准**（与执行权限策略无关）；拒绝 → 仍停留计划模式；批准 → 切回执行模式并恢复写工具

## I. 上下文与压缩

- [ ] **I1 自动压缩**：长对话触发上下文阈值 → 自动生成摘要、保留最近消息与工具组，界面 token 指示器下降
- [ ] **I2 工具输出剪裁**：一次大输出（如 `cat` 大文件）→ 工具结果头尾保留、中间省略标记
- [ ] **I3 小窗口工具瘦身（回归）**：供应商上下文设 8192 → 对话仍能跑（工具描述按 160/96/0 阶梯瘦身，不报"上下文超限"）

## J. 能力与 `.moyu` 命名空间

- [ ] **J1 设置页导入 MCP**（云工作区）→ 写入云机 `.moyu/shared/mcp.json`；右侧栏「云电脑已部署」出现**共享**徽标
- [ ] **J2 Bot 自装 MCP**：对话里让 Bot `install_mcp` → 写入该 Bot 的 `.moyu/mcp.json`；只有这个 Bot 的详情显示**自有**徽标
- [ ] **J3 不读 claude**：云机 `~/.claude` 有内容时，右侧栏不再显示「claude（外部）」条目（旧缓存条目也被隐藏）
- [ ] **J4 一次性迁移**：云机有旧 `~/.claude.json`/skills 时 → 首次在线盘点后自动复制进 `.moyu/shared`（marker 幂等；云机 claude 不受影响）
- [ ] **J5 离线缓存**：云机休眠时打开详情 → 显示上次盘点的落盘清单（不唤机）；唤醒后刷新

## K. 云电脑 / 终端 / 桌面

- [ ] **K1 唤醒休眠**：唤醒云机 → 状态变「已就绪」；空闲自动休眠（按设置）
- [ ] **K2 终端 PTY**：打开终端 → 交互式命令（如 `top`、`python3` REPL）可双向输入输出；停止按钮有效
- [ ] **K3 桌面操作**：让 Bot 用 `desktop_action` 打开网页并截图 → 返回截图产物可预览
- [ ] **K4 驱动切换**：设置里云电脑驱动可在 instabox / E2B / mock 间切换，切换后能力盘点与执行正常

## L. 定时任务 / 记忆 / 用量

- [ ] **L1 定时任务**：对话创建 cron 任务 → 设置页可见、到点执行、可暂停/恢复/关闭
- [ ] **L2 记忆**：`remember` 一条 → 新会话 `recall` 能检索到；记忆页可增删改
- [ ] **L3 用量统计**：跑几轮对话后 → 用量页显示 token 统计与上下文构成

## M. 数据与同步

- [ ] **M1 重启持久化**：重启 App → 会话/目标/清单/记忆/定时任务都在；每 bot 目录不变
- [ ] **M2 同步服务端**：部署 apps/web 到服务器 → 桌面端配置同步地址与 token → 会话/消息互通（改动 ≤30s 可见）
- [ ] **M3 工具清单防回退（回归）**：编辑 Bot 保存后 → `settings.json` 里该 Bot `tools` 不应从 `[]` 退化为旧清单；重启后检查工具仍全量

## N. 打包版

- [ ] **N1 安装**：关闭旧版 → 运行 `MoyuBot.Setup.0.1.3.exe` → 打开后 A~L 抽查三项通过
- [ ] **N2 标题区分**：开发者版标题为 **MoyuBot Dev**；打包版为 **MoyuBot Desktop**——以后测新功能认准 Dev 或新安装包
