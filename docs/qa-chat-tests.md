# MoyuBot 对话测试指令集（手工验收 · 只发消息即可测）

> 每条直接复制发送给任意 Bot。按顺序跑，失败记录「工具行 + 胶囊区 + 报错」截图。
> 前提：用最新构建（开发者版 **MoyuBot Dev** 或安装包 `MoyuBot.Setup.0.1.3.exe`），Bot 工具全量（编辑页全开）。

---

## T1 · 工具全量

**发送：**

```
列出你现在能调用的全部工具名，逐个数出来，不要省略
```

**预期：** 23 个，包含 `set_goal / update_goal / todo_write / ask_user / spawn_agent / run_script / subagent_fork / job_list / job_kill`（旧 15 个只是子集）。

---

## T2 · 立目标

**发送：**

```
用 set_goal 给这次会话立个目标：整理一份 moyubot 工具清单摘要。验收条件三条：(1) 列出全部工具名 (2) 按功能分组 (3) 标注哪些需要联网。autonomy 设 until_done。设好后先继续做第一条。
```

**预期：** `set_goal` 成功；头部目标胶囊 `目标 ✓ 0/3 ⟳ 0/8`；Bot 开始干活。

---

## T3 · 任务清单

**发送：**

```
用 todo_write 立一个三件事的清单：(1) 统计工具数量 (2) 按功能分组 (3) 标注联网需求
```

**预期：** 头像左侧出现清单胶囊 `0/3`；hover 显示三项。

---

## T4 · 完成一项

**发送：**

```
清单第一项做完了，用 todo_write 更新清单，第一项标 done
```

**预期：** 胶囊变 `1/3`。

---

## T5 · 全部完成 → 胶囊消失

**发送：**

```
把剩下两项也做完，用 todo_write 全部标 done
```

**预期：** 胶囊短暂显示 `3/3` 后**自动消失**；消息流保留“任务清单已更新”工具行。

---

## T6 · 新一轮清单重现

**发送：**

```
再立一个新清单：检查 moyubot 的定时任务功能是否可用（两项即可）
```

**预期：** 清单胶囊重新出现。

---

## T7 · 目标受阻（续航暂停）

**发送：**

```
用 update_goal 把当前目标标为 blocked，note 写"演示：假装被卡住了"
```

**预期：** 目标胶囊变琥珀色「续航暂停」，浮层内有「续跑 5 轮」。
若 Bot 回答“没有 update_goal”——说明工具未启用，先去编辑页确认全开。

---

## T8 · 带证据完成目标

**发送：**

```
继续把三条验收条件都做完，全部满足后用 update_goal 标记 complete，每条附证据
```

**预期：** `update_goal complete` 成功 → **目标胶囊消失**；条件未满足就标完成会被拒绝并要求补证据。

---

## T9 · 子代理并行（spawn_agent）

**发送：**

```
用 spawn_agent 并行派 3 个子代理：分别总结 cloud_* 工具、记忆工具、联网工具的用途，最后汇总
```

**预期：** 头部子代理胶囊 `⟳ 1/3 → 2/3 → 子代理 3`；工具卡逐个子任务显示进度；全部只读完成。

---

## T10 · 工作流编排（run_script）

**发送：**

```
用 run_script 写个脚本：用 agent() 派两个子代理分别总结云电脑工具和定时任务工具，两个都返回后拼成一段话作为返回值
```

**预期：** 子代理胶囊计数增加；工具行显示“工作流完成 · 2 个子代理 · N 个阶段”。

---

## T11 · 分身（subagent_fork）

**发送：**

```
用 subagent_fork 带着当前对话上下文继续：针对刚才的汇总，指出最值得深挖的一点并展开
```

**预期：** 胶囊里多出一个**分身批次**（浮层内虚线分隔、可见任务）；返回值明显引用了本对话上下文。

---

## T12 · 子代理清单与续聊

**发送：**

```
用 subagent_list_agents 列出这个对话派过的所有子代理
```

**预期：** 每个一行（id / 任务 / 运行中或已结束）。

**再发送：**

```
用 subagent_control 向刚才第一个子代理追问：把你的结论压缩成一句话
```

**预期：** 该子代理被**重新唤醒**干活并返回新结论（token 计数在涨）。

---

## T13 · 提问卡（ask_user）

**发送：**

```
用 ask_user 问我一个开放问题（比如我更喜欢哪种汇报风格），等我回答后再继续
```

**预期：** 输入框上方弹提问卡（非全屏遮罩）；Ctrl+Enter 发送回答后 Bot 引用回答继续；Esc 或“跳过” → Bot 说明“用户跳过”并给出假设。

---

## T14 · 计划模式

**先切到计划模式，再发送：**

```
帮我给工具清单文档加一节"只读/可写"标注
```

**预期：** Bot 只读核查后提交 `exit_plan_mode` 计划；**必须你批准**才执行；拒绝则留在计划模式。

---

## T15 · 文件附件（先往窗口拖一个 xlsx/txt 再发送）

**发送：**

```
我发的附件文件里有什么？用工具读它，然后总结三行
```

**预期：** Bot 收到附件路径提示（`[附件文件] …路径 uploads/…`），用工具读到内容并总结。

---

## T16 · 长期记忆

**发送：**

```
用 remember 记住：我最喜欢蓝色的界面
```

**新开会话后发送：**

```
用 recall 查一下我喜欢什么颜色
```

**预期：** 检索出「蓝色」。

---

## T17 · 定时任务

**发送：**

```
用 schedule_task 创建一个每天 9:00 的定时任务：汇报当前时间并简短问候
```

**预期：** 创建成功并给出任务 id；`list_tasks` 可查到。

---

## T18 · 桌面操作（云机在线）

**发送：**

```
用 desktop_action 打开 https://example.com 并截图，然后告诉我页面上写了什么
```

**预期：** 返回截图产物（可预览）+ 页面文字描述。

---

## 执行顺序

T1 → T2 → T3~T6（清单闭环）→ T7~T8（目标闭环）→ T9~T12（子代理全家桶）→ T13 → T14 → T15 → T16 → T17 → T18。
