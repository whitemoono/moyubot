# 0.2 系列更新说明（v0.1.9 → v0.2.4）

> 归档用途：v0.1.1–v0.1.3 各有单独文件，这一段此前只存在于 git 历史里。
> 注：本地 tag 目前到 `v0.2.1`，`v0.2.2` / `v0.2.3` / `v0.2.4` 需要补打 tag。

## v0.1.9

- 本地工作区的文件交付能正确解析并打开（此前 `@workspace_local/` 前缀与落点不一致，预览会报"文件不存在"）。
- 发布脚本改为写入真实的 release 说明，不再只有一个 compare 链接。

## v0.2.0

- **Office 生成落地**：`make_spreadsheet` / `make_document` / `make_slides` 三个工具，纯 JS 实现（ExcelJS / docx / pptxgenjs），不依赖 Python 或系统库；本机与云机跑同一份生成逻辑。
- **内置文件查看器**：文本、Markdown、CSV、JSON、图片、PDF 可直接看；云机文件给下载入口。
- `deliver_file` 让文件以对话卡片出现，模型不再把文件名重复写成行内代码。

## v0.2.1

- docx / xlsx 可以在应用内打开（mammoth / SheetJS 解析）。
- 修正本地文件路径与下载按钮：本地文件显示「打开所在目录」，云机文件显示「下载」。

## v0.2.2

- 一次交付只出一张文件卡片（生成 + 显式 `deliver_file` 不再重复）。
- 本地文件不再显示「下载」。

## v0.2.3

- `install_skill` 支持安装"已经躺在云机上"的技能：在云机侧校验 `SKILL.md`，复制进该 Bot 的 `.moyu/skills/<slug>` 并登记绑定，不再报"目录必须在当前工作区内"。
- 修复：云端安装的目录名会保留 `..`（落点可能变成 `.moyu/skills/..`）、缺少体积/文件数/符号链接限制、重复安装会堆出多条设置记录。

## v0.2.4

- **步数软暂停**：单轮工具调用触顶不再判为失败——保留全部工具结果，界面出现琥珀色提示与「继续」按钮；`until_done` 自动续航会直接续跑。默认步数上限 32 → 64。

## 本分支未发布（0.2.5 候选）

- 云机 Office 生成链路修复：以前云机分支必然 `exit 2` 后静默回退本机（每次还白传 3 MB 运行时）；现在直接 `require` 运行时，按内容哈希复用，清理 `_office/` 残留，失败会在工具摘要里明说。
- 预览 HTML 统一过 DOMPurify；`artifact:read-bytes` 加 16 MB 上限。
- `Store.close()`：退出与切换数据目录时释放 SQLite 句柄；顺带修好 Windows 上恒挂的 13 条测试，并发现一条一直没生效的路径断言。
- 统一 `pnpm test`（216 条用例）+ 代码体检棘轮 `pnpm lint` + CI 工作流。
