# 首次设置与共享用户资料

新用户首次打开应用时，按以下顺序完成设置：

1. 选择内置头像或上传图片，填写 1–40 字的用户名。默认头像为 DeepSeek。用户名必填，不接受换行和控制字符。
2. 保存 InstaBox 云电脑名称、API 地址和密钥，或选择「暂时跳过」。保存不创建、不唤醒机器。密钥继续使用 Electron safeStorage 存储。
3. 确认本地工作目录，支持直接编辑路径或原生文件夹选择器。完成时创建目录并验证写入权限。

Windows 发布版默认本地工作路径为可执行程序所在目录的 `workspace` 子目录；开发版是仓库目录的 `workspace`。安装在不可写位置时提示选择其他可写目录，不静默迁移或提升权限。已有用户自选的目录保持不变。

跳过云电脑后进入本地工作区；没有本地 Bot 时创建一个「本地助手」，默认执行前确认。配置云电脑则进入云电脑工作区。完成状态保存在设置里，后续启动不重复展示；中途退出会从已保存步骤继续。

已有安装升级时不重新运行引导，不改变原 Bot、工作区和聊天。用户名在「设置 → 个人资料」中修改，左下角名称同步更新。

`AppSettings.userName` 是本机所有工作区共享的用户资料。每次模型请求都将当前名称以 JSON 数据形式提供给本地、云电脑、群聊和定时执行中的 Bot，优先于旧记忆中的称呼。修改名称不重写聊天或私人记忆。

验证：`node --test scripts/profile.test.cjs scripts/workspaces.test.cjs`；构建后运行 `pnpm --filter @moyu/desktop exec electron --no-sandbox ../../scripts/onboarding-smoke.cjs`。界面测试使用独立数据，验证头像、必填姓名、云电脑跳过及保存分支、目录权限错误、自选目录、本地执行、修改姓名、重启继续与完成状态；不访问真实云账户。
