# MoyuBot v0.1.3

下载 `MoyuBot.Setup.0.1.3.exe`，按向导选择安装目录并完成安装。升级保留现有聊天和设置。

## 上下文与缓存可观测

- 输入框下方新增三段状态栏：**会话统计**（模型用时、工具调用用时、平均首 token、输出速度）、**Token 用量**（累计 token、缓存命中、未缓存输入、缓存读取、输出）、**上下文已用**（系统提示词 / 工具定义 / 对话消息的实时拆分与窗口占比）。悬停或点击任一段展开对应面板。
- 三段拆分由 `@moyu/core` 在每次组装请求时通过 `context_usage` 事件回报，与真正发给模型的口径一致；会话快照会本地持久化，重启后仍显示上次占用。
- 修复累计回复时 `cachedTokens` 被丢弃的问题，多步任务也能正确统计缓存命中。
- 修复上下文窗口识别：`modelProfile` 现在忽略中转站前缀并按模型族匹配（DeepSeek V4/V4.1、GLM-5.x、Kimi-K3/K2.x、Qwen3.8、MiniMax-M2/M3、Gemini 2.5/3），未知模型仍保守回退 32768。
- 「获取模型」会一并读取供应商 `/v1/models` 的 `display_name`、`context_window` 与 `max_output_tokens`，模型显示可读名称并在下方与悬停处保留完整 ID；同名模型可凭 `workbuddy/`、`codearts/` 等前缀区分。
- 新增**压缩阈值**设置，可按模型（供应商 → 高级）或按 Bot（生成与任务预算）覆盖，留空沿用窗口 90%，取值大于等于窗口时使用完整窗口。生效顺序：Bot 覆盖 → 模型设置 → 窗口 90%。

## 缓存命中实测

系统提示词原先带有精确到秒的当前时间，导致每一轮前缀都不同、缓存几乎不命中。现在把易变信息移到当前用户消息末尾，前缀保持稳定：同一长前缀连续请求实测缓存读取约 **97%**（此前会话实测约 10%）。注意部分上游（如 GLM-5.3-Flash）不回报缓存字段，命中率会显示为空。

## 推理强度

模型选择器旁新增「思考」按钮，弹出滑块卡片可选 **低 / 中 / 高**，支持点击、拖动与键盘调节，写入 `bot.generation.reasoningEffort`；OpenAI 兼容供应商与显式配置了 `openai-effort` 的模型都会显示。

## 能力自助安装与联网搜索

- 新增 `install_mcp` / `install_skill` 工具：在对话中粘贴 `mcpServers` JSON 或指定工作区内的技能目录即可安装，并自动绑定到当前 Bot。stdio 的 `command` 必须是本机存在的绝对路径，技能目录必须位于工作区内且含合法 `SKILL.md`；审批策略为「每次确认」时会先请求批准。两者默认不在隐式工具集合中，需要在 Bot 编辑页勾选。
- 新增 `web_search` 工具，返回标题、链接与摘要，配合 `web_fetch` 形成"搜索 → 抓取"闭环。后端默认 **Bing 网页（免密钥）**，可在「设置 → 能力 → 联网搜索」切换 Serper、Brave、Bing API、SearXNG 或 DuckDuckGo；密钥与供应商密钥同样加密保存。
- MCP 与技能仍按设计运行在本机：`workspaceId` 只表示分组与可见范围，云端能力继续由 `cloud_exec` / 文件工具承担。

## 对话与界面

- 长回复超过 1600 字自动折叠，底部渐隐并提供透明的「展开全文 / 收起」入口。
- 长会话渲染优化：Markdown 与语法高亮按内容缓存且只在流式结束后高亮一次，消息列表项记忆化，屏外消息使用 `content-visibility` 跳过布局绘制。实测切换右侧栏约 20–30ms。
- 头像动效：生成中复用角色引擎的 `thinking` 并循环 `curious / thinking / searching`（含三点特效，此前被 `preservePortrait` 关闭）；回复完成播放 `waking`、停止播放 `alerting` 后回到待机；侧栏与置顶头像跟随该 Bot 会话活动，右侧详情栏与消息作者头像保持待机；离屏或窗口隐藏时暂停动画引擎。
- 修复「已停止生成」的头像只在极短窗口内有动画、随后退化为静态剪影的问题。

Windows x64 安装包。校验值见附件 `SHA256SUMS.txt`。

验证：core / 主进程 / 渲染层类型检查，生产构建与 NSIS 打包，`web_search` 与 `context_usage` 链路端到端实测。
