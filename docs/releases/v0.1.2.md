# MoyuBot v0.1.2

下载 `MoyuBot.Setup.0.1.2.exe`，按向导选择安装目录并完成安装。升级保留现有聊天和设置。

## 模型接入

- 模型适配统一迁移到 pi-ai，OpenAI 兼容、Anthropic 与 Gemini 三条链路共用同一套流式、缓存、思考与工具调用处理；Google 请求仍经桌面端网络设置转发。
- 「设置 → 模型供应商 → 配置模型额度」可分别设置每个模型的上下文上限、最大输出与思考接口。未知模型默认上下文 32768、单次输出 8192。
- Bot 编辑页新增「生成与任务预算」：任务生成轮数、累计生成额度和最长运行时间，默认每任务 32 轮、131072 生成 tokens、20 分钟。超出后明确报告任务未完成并保留已执行结果。
- 输出或工具参数被截断时自动重试最多 3 次，只重发完整的小调用，不重放已成功的工具。

## MCP 与 Skills

- 新增「设置 → MCP 与 Skills」，粘贴 `mcpServers` JSON 即可导入 stdio 或 Streamable HTTP 服务，测试连接后在 Bot 编辑页或右侧详情栏启用。
- 技能通过选择包含 `SKILL.md` 的目录导入，模型先读取技能目录，再按需调用 `load_skill` 加载正文与相对路径资源。
- 右侧详情栏显示每个 Bot 的能力开关、实时连接状态、工具列表和最近加载时间。`env` / `headers` 走桌面端密钥存储单独保存。

## 对话与界面

- 修复回复反复停在「正在整理上下文」的问题：同步记录改为合并到正在使用的对象，不再替换整个对话，已生成的摘要可以复用。
- 每条回复上方显示 Bot 头像和名称，群聊与单聊一致；回复内的工具卡片默认折叠，需要时再展开。
- 切换 Bot 或打开会话时直接定位到最新消息底部，不再从上往下滚动。

## 应用内更新

- 「设置 → 关于」可检查新版本，下载 Windows x64 安装包并显示进度，支持取消与重试；SHA256 校验通过后可点「重启并安装」，保留聊天和设置。
- 检查与下载跟随系统代理；有任务运行时会提示先结束后再安装。

Windows x64 安装包。校验值见附件 `SHA256SUMS.txt`。
