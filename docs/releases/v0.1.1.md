# MoyuBot v0.1.1

下载 `MoyuBot.Setup.0.1.1.exe`，按向导选择安装目录并完成安装。升级保留现有聊天和设置。

- Bot 右键菜单新增「编辑 Bot」，可直接打开完整配置窗口。
- 群聊列表支持折叠、上移和下移；右键可编辑群名、添加或移除成员、删除群聊。删除后隐藏群聊并保留本地记录。
- 点击群聊顶部名称可打开右侧栏，查看成员和回复顺序、编辑群聊、管理本群记忆及对话文件。
- 群聊可使用工作区共享电脑、桌面预览和终端。成员依次执行，保留各自工具和审批权限；群聊记忆与私聊分开保存。
- 每个供应商可选择「直连」或「跟随系统」网络模式，默认直连。需要系统代理的中转服务可单独设置。
- 优化本机 PowerShell 和云电脑终端的命令输入框、执行及停止状态。
- 长期记忆支持独立弹窗、搜索及手动管理；绘图统一使用供应商图像 API，无需唤醒云电脑。
- 修复 Windows 打包程序读取内置界面资源失败导致无法打开窗口的问题。

Windows x64 安装包。校验值见附件 `SHA256SUMS.txt`。

验证：生产构建、类型检查、核心回归测试、群聊与网络模式 Electron 测试，以及打包程序检查。共享云电脑操作使用模拟环境验证，本次未进行真实云桌面连接测试。
