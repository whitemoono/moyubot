## 更新内容

### 三个页面重新排版（只改版式与分组，逻辑不变）

**工具页**
- 39 个工具从平铺改成 **12 个功能分组**（电脑操作 / 代码编辑 / 文档生成 / 文件交付 / 本机文件 / 联网 / 记忆与检索 / 目标与清单 / 定时任务 / 多智能体 / 能力安装 / 计划模式），每组可折叠并显示启用数
- 顶部加**搜索框**，按工具名或说明过滤
- 每个工具标出**有几个 Bot 在用**，未启用的标灰

**MCP 与 Skills**
- 从上下堆叠改成**左右双栏**：左 MCP、右技能，一屏能同时看到两边
- 云电脑已部署清单归入各自那一栏（虚线边框 + 自有/共享徽标），不再混在页面底部
- 「导入 MCP JSON」收进可折叠区域，常用操作（测试/移除）常驻
- 技能栏右上角直接放导入按钮

**Bot 编辑器**
- 工具开关从一屏 39 个改成**按功能分组折叠**，每组标题显示 `已启用/总数`
- 与工具页共用同一套分组定义，两处看到的结构一致
