## 更新内容

### 三个页面重新排版（只改版式，逻辑不变）

**工具页**
- 39 个工具从平铺改成 **12 个功能分组**（电脑操作 / 代码编辑 / 文档生成 / 文件交付 / 本机文件 / 联网 / 记忆与检索 / 目标与清单 / 定时任务 / 多智能体 / 能力安装 / 计划模式）
- **默认全部收起**，只显示每组标题与数量，想看哪组点开哪组
- 顶部**搜索框**按名字或说明过滤，命中的组自动展开
- 每个工具标出有几个 Bot 在用，未启用的标灰

**MCP 与 Skills**
- 左右双栏：左 MCP、右技能
- 每栏内部**按来源分成可折叠组**：工作区配置 / 云电脑共享 / 各 Bot 自有，组标题带数量
- **默认全部收起**，一屏看完分组概览；点开才展开条目
- 「添加」按下后导入表单就地展开，不再长期占地方

**Bot 编辑器**
- 工具开关按功能分组折叠，每组显示已启用/总数，与工具页共用同一套分组
