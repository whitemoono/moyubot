# Bot 头像与动作

头像身份由用户选择的角色决定，动作由实际事件决定。左栏、顶部胶囊和右侧资料面板跟随各自 Bot 的活动；回复前使用同一个 Bot 的头像。所有状态保留人物造型与配色，使用表情和姿态表达动作，不把角色整体变形成符号。

| 状态 | 触发时机 | 动作与提示 |
| --- | --- | --- |
| 待命 | 没有正在进行的请求 | 眨眼、呼吸；随机歪头、微笑、俏皮摆动、小跳、得意、害羞、轻笑；鼠标移入时微笑回应 |
| 正在发送 | 发送消息到桌面主进程 | 轻轻抬头回应 |
| 正在思考 | 请求开始、推理片段、工具完成后继续处理 | 歪头思考、视线上移，状态文字旁显示脉冲点 |
| 正在查找资料 | 网页抓取、召回记忆、读取文件 | 搜索与视线动作 |
| 正在操作电脑 | 执行命令、写入文件 | 工作动作 |
| 正在回复 | 模型开始输出回答文字 | 低头专注、有节奏地点头 |
| 正在生成图片 | 调用绘图工具 | 轻摆与小幅浮动 |
| 正在整理记忆 | 调用 remember | 轻缓呼吸与视线移动 |
| 正在安排任务 | 创建定时任务 | 工作动作，文字说明具体任务 |
| 正在整理上下文 | 自动压缩开始，直到完成或失败 | 平稳浮动，显示整理上下文状态 |
| 等待你的确认 | 工具授权弹窗等待回应 | 倾听动作；确认或拒绝后立即退出 |
| 正在唤醒电脑 | 当前 Bot 的云电脑工具正在等待唤醒 | 唤醒动作；纯聊天不会跟随其他 Bot 的电脑活动 |
| 电脑休眠中 | 右侧电脑卡片的设备已休眠或正在进入休眠 | 当前 Bot 的灰度头像闭眼、轻轻呼吸，旁边浮动 z 字样 |
| 回复完成 | 一轮正常结束 | 短暂微笑 2.4 秒，随后待命 |
| 遇到问题 | 供应商失败、工具失败、压缩失败 | 抬眼、短暂轻摇，回复头像保留错误标记；缺少密钥时显示配置入口 |
| 已停止生成 | 用户主动停止 | 短暂收敛动作，保留已生成的文字，不作为故障告警 |

## 消息与性能

- 右侧电脑卡片使用当前 Bot 的头像，统一灰度显示，动作只跟随该工作区电脑的真实状态。开机时睁眼、抬头并显示三点进度；就绪后回到待命。上传头像使用轻缓呼吸与开机浮动，减少动态效果时保持静态。上方资料头像继续保留原配色与 Bot 活动状态。

- 点击右侧资料面板的大头像，可在小窗内预览内置角色、主题色或上传图片，保存后同步到置顶区、列表、顶部与消息头像。置顶头像展开时 80px、每行两个，单个置顶居中；收起时 48px，右侧头像 88px。
- 上传支持 PNG、JPG、WebP、GIF，最大 8 MB；居中裁剪为 256px WebP 后保存在本地配置，不依赖原文件路径。图片头像保持静态，切回内置角色后恢复动作。
- 身份头像待命时，首次 1.2–2.4 秒后展示随机动作，动作持续 1.8–2.8 秒，再休息 3.2–6.2 秒；避免连续重复同一个动作。鼠标移入时立即回应，随后恢复随机节奏。
- 思考、工作、等待确认等实际状态会立即取消随机动作与待命计时；处理结束后恢复待命表情。随机表情不改变 Bot 的业务状态和状态文字。
- 只有当前正在生成的回复播放实时动作。旧消息使用轻量静态 SVG，没有逐条动画循环。
- 最新一条完成回复会短暂展示完成动作；旧失败消息保留带错误标记的角色头像。
- 活动按固定对话隔离，切换 Bot 或多个 Bot 同时工作时互不覆盖。新一轮请求不会把上一条回复重新变成“正在思考”。
- 用户停止会保存 `message.stopped`，重载后仍能识别；未完成的工具不再无限显示执行中。
- 应用或系统开启减少动效时，头像使用静态角色，文字状态继续更新。
- 缺少 API Key 等错误只展示一次，避免“没有回复”占位和同一错误重复出现。
