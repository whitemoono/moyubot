## 更新内容

### 本地技能归档 + 能力分组

- **本地技能归档**：安装新技能时，归档到发起该技能的那个 Bot 的家目录 `.moyu/skills/<name>`（与云电脑的「自有」语义一致）；存量技能会在启动时自动迁移到归属 Bot 的目录，迁移幂等、不破坏已有绑定。
- **右侧检查器分组**（本地工作区）：MCP 与技能从平铺列表改为「自有 · 已启用 / 其它 · 可添加」两组，带徽标，仍可随时勾选切换绑定。
- **设置页绑定标注**：「MCP 与 Skills」页条目显示该能力绑定到哪些 Bot。

### Bot 工作目录支持绝对路径

- 在 Bot 编辑页可为单个 Bot 设置自定义工作目录（绝对路径），让该 Bot 在指定目录里干活；想让几个 Bot 共用一棵代码树，就各自填同一个路径。
- 越界访问仍被拒绝（`safePath` 只允许根内路径）。

### 模板市场

- web_fetch 与模板市场共用同一套出站 URL 守卫（仅允许 https、来源白名单）。
