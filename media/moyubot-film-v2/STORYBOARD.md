## 接入说明原文

1. 注册 InstaBox 并创建云电脑，获取 API Key。
2. 在 MoyuBot「设置 → 云电脑」中填入 API Key，保存后刷新机器列表。当前设置页标题为「共享云电脑」。
3. 在「Bot 管理」中配置模型、权限和工具，就可以开始对话。

InstaBox 有免费试用，欢迎用来体验 MoyuBot 的云电脑接入。模型供应商需要单独配置；云电脑的费用和试用规则以 InstaBox 账户及官方说明为准。

## 功能准确性

依据当前的工作区、Bot 管理、云电脑桌面、命令面板与核心工具代码设计。命令面板每条命令独立执行，完成后返回结果。视频中的文字输入表示提交命令，不表示 PTY 或实时流式终端。桌面默认只读是指用户预览；Bot 可以操作云桌面。接管需等待当前命令结束，再暂停 Bot 电脑工具。

定时任务需应用运行，本地任务还需本地电脑在线。群聊、记忆、定时任务及用量已经实现。本片的规划区只显示跨设备 / PWA、MCP、MoyuChain 模型额度互助市场；MoyuChain 不属于已上线的云电脑能力。
