## 声音设计

- 旁白：Microsoft Xiaoxiao Neural 中文合成语音。20 个片段独立生成，去掉前后静音，再对齐字幕；较长片段以保留音高的轻微变速适配镜头。
- 配乐：原创程序合成，100 BPM，D 大调。Dmaj9 / Bm7 / Gmaj9 / Asus2 循环；低音、柔和铺底、玻璃拨弦与克制鼓点构成主体。D / F# / A 三音作为开场与结尾的品牌动机。
- 音效：角色点音、转场风声、命令打字与确认音全部由代码合成。角色入场声像从左到右铺开。
- 混音：旁白出现时音乐自动降低；48 kHz 立体声，综合响度目标 -16 LUFS，真峰值目标 -1.5 dBTP。另提供旁白、音乐、音效和最终母带，便于二次剪辑。
